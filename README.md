# Бот для поиска вакансий и подготовки откликов

Telegram-бот ищет вакансии через API hh.ru и автоматически пишет короткие персональные тексты откликов через DeepSeek. После генерации бот отправляет текст и ссылку на вакансию: пользователь открывает HH и подтверждает отправку отклика.

## Файлы

- `main.py` — Telegram-бот, выбор города, профиль кандидата и автоматическая генерация откликов.
- `parser.py` — запрос к API hh.ru и расчёт средней зарплаты и медианы.
- `deepseek.py` — OpenAI-совместимый клиент `chat/completions` для DeepSeek.
- `knopki.py` — список городов и клавиатуры.
- `.env.example` — пример переменных окружения.

## Запуск

1. Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

2. Создать файл `.env` рядом с `main.py` на основе `.env.example` и вставить токены:

```powershell
Copy-Item .env.example .env
```

Либо задать переменные окружения напрямую в PowerShell:

```powershell
$env:TELEGRAM_BOT_TOKEN = "токен от @BotFather"
$env:DEEPSEEK_API_KEY = "ключ DeepSeek"
$env:DEEPSEEK_BASE_URL = "https://api.deepseek.com"
$env:DEEPSEEK_MODEL = "deepseek-v4.1-flash"
```

Если используется обычный `cmd.exe`, откройте файл так:

```bat
copy .env.example .env
notepad .env
```

В открывшемся файле замените значения `TELEGRAM_BOT_TOKEN` и `DEEPSEEK_API_KEY`, сохраните его и снова выполните:

```bat
python main.py
```

`DEEPSEEK_BASE_URL` можно заменить на адрес совместимого прокси. Клиент сам добавит `/chat/completions`, поэтому подходят как `https://api.deepseek.com`, так и URL, который уже заканчивается на `/chat/completions`.

3. Запустить:

```powershell
python main.py
```

## Как пользоваться

1. Отправить боту `/start` и выбрать город.
2. По желанию отправить `/profile`, затем одним сообщением указать имя, навыки, опыт, стек и желаемую должность.
3. Написать поисковый запрос, например `python разработчик`.
4. Бот покажет статистику и первые вакансии, затем автоматически подготовит до пяти текстов отклика через DeepSeek.
5. Если нужно остановить текущую отправку, отправить `/stop`.
6. Открыть ссылку HH из сообщения и отправить готовый текст в форме отклика.

Если `DEEPSEEK_API_KEY` не задан, поиск вакансий продолжит работать, а бот сообщит, как включить генерацию.

## Примечания

- Тексты строятся только на данных из профиля и описания вакансии; модель получает инструкцию не выдумывать опыт и навыки.
- Профиль и результаты поиска хранятся в памяти и сбрасываются после перезапуска.
- HH может вернуть ошибку при слишком частых запросах; запросы имеют тайм-аут 20 секунд.
- В проекте нет авторизации HH и публичной интеграции для автоматической отправки отклика. Поэтому бот готовит текст и даёт ссылку, а финальное нажатие «Откликнуться» остаётся за пользователем.
