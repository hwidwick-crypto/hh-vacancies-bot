# Бот для поиска вакансий на hh.ru

Учебный проект: Telegram-бот на `pyTelegramBotAPI`, который ищет вакансии через API hh.ru и считает среднюю зарплату и медиану.

## Файлы

- `main.py` — запуск бота, команда `/start`, выбор города, приём профессии и отправка результата.
- `parser.py` — запрос к `https://api.hh.ru/vacancies`, средняя зарплата и медиана.
- `knopki.py` — список городов и клавиатуры.

## Запуск

1. Установить библиотеки:

```powershell
python -m pip install -r requirements.txt
```

2. Получить токен у `@BotFather` и вставить его в `main.py` вместо `ВСТАВЬ_СЮДА_ТОКЕН`.

3. В `parser.py` заменить `your_email@yandex.ru` на свою почту. hh.ru проверяет `User-Agent` и не любит адреса вроде `example.com`.

4. Запустить:

```powershell
python main.py
```

5. В Telegram отправить боту `/start`, выбрать город и написать профессию, например `python разработчик`.

## Как работает

1. Бот показывает кнопки с городами.
2. Город и профессия сохраняются в словарь `user_data` по `chat_id`.
3. `parser.py` делает запрос к hh.ru и получает первые 50 вакансий.
4. Средняя зарплата и медиана считаются вручную через циклы, без `statistics`.
5. В ответ бот отправляет статистику и первые 5 вакансий.

## Как считается зарплата

- Берутся только вакансии с валютой `RUR`.
- Если указана зарплата `from`, берётся она. Если `from` нет, но есть `to`, берётся `to`.
- Средняя считается вручную: сумма / количество.
- Для медианы список сортируется через `.sort()`, потом берётся середина. Если количество чётное, берутся два средних значения и делятся на 2.
- Загружается только первая страница, 50 вакансий.

## Ограничения

- `user_data` хранится в памяти, после перезапуска бота выбранные города сбрасываются.
- Токен пока лежит прямо в коде, для учебного проекта это нормально.
- hh.ru может вернуть ошибку, если часто отправлять запросы.
- Вакансии без зарплаты в статистику не попадают.

## Что можно улучшить

- вынести токен в переменную окружения;
- сделать постраничную загрузку, а не только первые 50 вакансий;
- добавить фильтр по опыту и графику;
- сохранять города в базу, а не в обычный словарь `user_data`.
